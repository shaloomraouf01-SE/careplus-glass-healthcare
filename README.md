# CarePlus — Glassmorphism Healthcare Website

A polished, responsive healthcare website featuring glassmorphism design, specialist discovery, interactive doctor profiles, and appointment previews. Built with HTML, CSS, and vanilla JavaScript.

> Frontend concept only. No real appointments, messages, payments or patient records are processed.

## Highlights

- Seven connected pages with a consistent teal and frosted-glass design
- Responsive navigation, translucent cards and soft background gradients
- Searchable doctor directory with specialty filters and profile dialogs
- Appointment preferences with URL preselection and a live visit summary
- Patient FAQs, contact preview and privacy information
- Keyboard focus styles, skip navigation and reduced-motion support
- No installation, framework or build step required

## Run locally

Extract the archive and open `index.html` in your browser. Keep all included files together. Google Fonts and Unsplash images require internet access.

## Publish

Follow [DEPLOYMENT-GUIDE.md](DEPLOYMENT-GUIDE.md) for repository setup and GitHub Pages deployment. Upload the extracted files, not the ZIP. The homepage must be at the repository root.

## Customize

Edit HTML files to change content and sample profiles. Shared appearance lives in `style.css`; interactions live in `script.js`. Keep doctor names and specialties consistent between profile cards and appointment options.

## Demo boundaries

Doctor names, experience, ratings and contact details are sample content, not verified practice information. Forms do not submit or persist input. Use fictional details for previews. External font/image providers and a hosting provider may receive standard connection information.

Before accepting real patient requests, verify clinic details and provider consent, replace placeholders, and implement a secure backend, actual scheduling, appropriate privacy disclosures and operational support.
